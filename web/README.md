# web

React Three Fiber static site: a 3D globe of the country exposure network,
with click-to-shock contagion simulation running entirely client-side.

```bash
npm install
npm run dev      # dev server
npm test         # vitest, checks lib/debtrank.ts and lib/eisenbergNoe.ts against
                  # the same fixtures used by model/'s pytest suite
npm run build
```

## Features

- **Two models, one click**: `DebtRank` (iterative distress propagation) and
  `Eisenberg-Noe` (equilibrium clearing vector) can be toggled live for the
  same shock. Both are TypeScript ports of the Python reference
  implementations (`src/lib/debtrank.ts`, `src/lib/eisenbergNoe.ts`), kept
  structurally identical to `model/debtrank_model/*.py` and checked against
  the same toy-network fixtures. The Eisenberg-Noe result is netted against
  an unshocked baseline clearing vector (see the comment in `App.tsx` next
  to `baselineShortfall`) — real cross-border bank liabilities routinely
  exceed a country's FX reserves, so an *unshocked* clearing vector already
  shows many countries "short"; netting against that baseline isolates the
  shock's marginal effect instead of just restating that mismatch.
- **Shock magnitude**: a 5–100% slider scales the initial shock instead of
  always simulating a full default.
- **Historical year scrubber**: drags across `network_snapshot`-shaped JSON
  files fetched on demand from `public/data/network/{year}.json`
  (2005–2025), rather than one static snapshot — see `src/lib/network.ts`'s
  `loadYearData`.

## Data

`src/data/network_snapshot.json` supplies static country metadata
(id/name/lat/lng) that doesn't change across years. Per-year financials and
exposure edges live in `public/data/network/{year}.json`, generated by
`data-pipeline/build_snapshot.py --by-year` (see that repo's README) and
copied in — not bundled into the JS chunk, so the initial load doesn't
balloon for 21 years of data.
